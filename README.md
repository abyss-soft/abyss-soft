# Hi, I'm Alexander
### Frontend / UI Engineer

Разрабатываю сложные пользовательские веб-интерфейсы, личные кабинеты и административные системы со сложной бизнес-логикой. Фокусируюсь на проектировании клиентской архитектуры, интеграции с REST API и оптимизации производительности при работе с большими объемами данных.

Закрываю полный цикл разработки: от UX/UI-проектирования и прототипирования до чистой адаптивной реализации в коде, интеграции с backend-сервисами и доведения до production.

### Ключевые компетенции

* **Архитектура & SPA:** Модульное разделение кодовой базы, изоляция слоя API, управление состоянием приложения, строгая типизация.
* **UI/UX & Производительность:** Создание адаптивных и mobile-first интерфейсов, проектирование компонентных дизайн-систем, оптимизация DOM-рендеринга и виртуализация тяжелых табличных данных.
* **Окружение & Интеграция:** Работа с современной Node.js-инфраструктурой, сборщиками, REST API / JWT, а также интеграция с гибридными/серверными шаблонами и backend-окружением.
