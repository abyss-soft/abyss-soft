# Hi, I'm Alexander

### Senior Frontend / UI & Automation Engineer

Разрабатываю сложные пользовательские веб-интерфейсы, личные кабинеты и административные системы со сложной бизнес-логикой. Фокусируюсь на проектировании клиентской архитектуры, интеграции с REST API и оптимизации производительности при работе с большими объемами данных.

Закрываю полный цикл разработки: от UX/UI-проектирования и прототипирования до чистой адаптивной реализации в коде, браузерной автоматизации, интеграции с backend-сервисами и доведения до production.

---

### Ключевые компетенции

- **Архитектура & SPA:** Модульное разделение кодовой базы, изоляция слоя API, управление состоянием приложения, строгая типизация.
- **UI/UX & Производительность:** Создание адаптивных интерфейсов, проектирование компонентных дизайн-систем, оптимизация DOM-рендеринга, мониторинг Core Web Vitals и виртуализация тяжелых данных.
- **Браузерная автоматизация & DX:** Управление headless-движками (Blink/Gecko), настройка прокси и сетевого окружения, интеграция автоматического тестирования и аудита производительности в CI/CD.
- **Окружение & Интеграция:** Работа с современной Node.js-инфраструктурой, сборщиками, REST API / JWT, а также интеграция с гибридными/серверными шаблонами и backend-окружением.

### Избранные репозитории и архитектурные концепты

#### Frontend & UI Performance

- **[vue-ag-grid-tree](https://github.com/abyss-soft/vue-ag-grid-tree)**  
  _Высоконагруженные интерфейсы и обработка данных._ Реализация сложных древовидных структур (Tree Data), оптимизация UI-рендеринга и минимизация перерисовок при работе с большими массивами информации.

- **[vue-rest-api-federal](https://github.com/abyss-soft/vue-rest-api-federal)**  
  _Архитектурный паттерн масштабируемого клиентского приложения._ Модульное разделение кодовой базы, изоляция сетевого слоя (API Interceptors), строгая типизация моделей данных без использования `any`.

#### Browser Automation, Network & Tooling

- **[Chrome-proxy-manager](https://github.com/abyss-soft/Chrome-proxy-manager)** & **[Firefox-proxy-manager](https://github.com/abyss-soft/Firefox-proxy-manager)**  
  _Управление сетевым окружением._ Утилиты и конфигурации для программного управления прокси-серверами, ротации IP-адресов и изоляции сетевого трафика в Chrome и Firefox.

- **[headless-browser_autotest](https://github.com/abyss-soft/headless-browser_autotest)**  
  _Сквозное (E2E) тестирование._ Инфраструктура для запуска автоматизированных сценариев тестирования веб-приложений в безынтерфейсном режиме (headless-mode).

- **[lighthouse-testing](https://github.com/abyss-soft/lighthouse-testing)**  
  _Автоматизация аудита производительности._ Интеграция Google Lighthouse для системного контроля Core Web Vitals, SEO и параметров доступности (Accessibility) в процессе CI/CD.
